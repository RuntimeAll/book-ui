# book-ui

misikt 教师端复刻 — **前端 Web**。

## 项目说明

功能级复刻 [misikt 教师端](https://www.misikt.com/teacher/) 的 **题库 + 卷库** 两个核心模块的业务流。

- **范围**：题库 + 卷库 only
- **UI 自由度**：可选用更优设计，不拘泥原网站一比一还原；有更好的轮子直接用，**不无故造轮子**
- **认知工程**：[misworkplace](https://github.com/RuntimeAll/misworkplace) — 项目认知层 + 任务卡 + 数据建模
- **后端**：[book-server](https://github.com/RuntimeAll/book-server)

## 状态

🟢 基建中（V0.0）— 待初始化工程结构。
